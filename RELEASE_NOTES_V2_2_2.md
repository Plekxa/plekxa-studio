# Plekxa Creator Studio v2.2.2

## Professional deliverable upload UX
- Byte-level Cloudflare R2 upload progress for single and multipart uploads.
- Per-file progress indicators for files and folder uploads.
- File size and version displayed after upload.
- Multi-select and Select all for uploaded deliverable files.
- Bulk delete removes both the R2 object and database record.
- Accepted/approved deliverables are protected from creator deletion.
- Clear success, failure and destructive-action confirmation states.
- Existing Index Certificates area and notification integration retained.
