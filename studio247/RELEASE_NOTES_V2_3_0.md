# Plekxa Creator Studio v2.3.0 — Commission Workflow Hardening

- Public Studio homepage aligned to the September 2026 Asset / Project / Index model; PPR and old Experience-product language removed.
- Deliverables now use an explicit Upload → review files → Submit for review flow.
- Project reference files supplied by Plekxa are downloadable inside the Commission workspace.
- Wider, message-style conversation UI.
- Creator messages and deliverable submissions create Enterprise notifications; operational email is also sent where configured.
- Contract detail query repaired and contract-signature events notify Enterprise.
- Earnings continue to read the Creator earnings ledger; new SQL projects Index allocations into that ledger.
