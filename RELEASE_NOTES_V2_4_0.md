# Plekxa Creator Studio v2.4.0
- Applications remain portfolio/fit applications; private production files are not exposed to applicants.
- Commissioned Directors receive a Director Room for their Project.
- Directors can upload beats/instrumentals/reference files for accepted/commissioned contributors.
- Directors can oversee private contributor workspaces without exposing one creator's conversation to another creator.
- Each Project maps to one reserved primary Asset; related completed Assets can later be grouped into Collections/albums by Plekxa.
